StudioxAstro template

Studiox is a creative agency site built with Astro 7, Tailwind CSS 4, GSAP and Lenis. This page covers how to install it, where every piece of content lives, how to change colours, fonts and images, how the animations are set up, and how to deploy it.

Getting started

Requirements

  • Node.js 22.12 or newer
  • Bun (the project ships a bun.lock). npm also works.

Install and run

cd studiox
bun install
bun run dev

The site runs at http://localhost:4321.

Site settings

Set your domain first: site in astro.config.mjs drives canonical URLs, Open Graph URLs, the sitemap and robots.txt.

export default defineConfig({
  site: 'https://studiox.studio',
  integrations: [sitemap()],
  ...
});

Email, navigation, footer and social links are in src/data/site.ts:

export const EMAIL = 'hello@studiox.studio';

export const NAV_LINKS = [
  { label: 'Services', href: '/services' },
  { label: 'Work', href: '/work' },
  ...
];

export const SOCIAL_LINKS = [
  { label: 'LinkedIn', href: 'https://www.linkedin.com' },
  ...
];

The site name, default title, description and share image are in src/utils/seo.ts. The logo mark is drawn from MARK_RECTS in site.ts, and the favicons are in public/.

Editing content

Home copy is in src/data/home.ts, and the copy for Studio, Services, Work, Journal and Privacy is in src/data/pages.ts. Projects, articles and services are Markdown files in content collections, with schemas in src/content.config.ts. If a field is missing or wrong, the build names the file.

Add a project

Copy a file in src/data/projects/ and rename it. The file name becomes the URL: acme.md builds /work/acme.

Colours and fonts

Colours and easings are tokens in src/styles/variable.css. Tailwind reads them, so bg-cobalt or text-muted follow any change. One script also sets colours directly: INK, ACCENT and EMPTY at the top of src/scripts/pixel-stat.ts.

Type

The type scale (type-display, type-h1 to type-h4, type-body and so on) is in src/styles/typography.css. Breakpoints are 810 px, 1200 px and 1440 px.

Fonts

Geist loads through the Astro Fonts API from src/assets/fonts/Geist-Variable.woff2. To change it, add your file and edit the fonts entry in astro.config.mjs, then update --font-geist in variable.css. The kinetic wordmark animates the weight axis, so a variable font keeps that effect.

Images

The demo photos are not included in the download. Every image is a grey placeholder labelled with the size to upload for that slot, so you can see what fits the frame. Replace each one with your own image at the same path. The hero video is a placeholder too.

Photos live in src/assets/images/ and go through astro:assets, which resizes them and writes WebP at build time. Markdown files point to them with a relative path. The hero video is public/videos/hero.mp4.

Frames crop with object-cover and change shape between phone and desktop, so keep the subject near the centre. The recommended size matches the main desktop frame at 2× for sharp screens.

Animations

Everything starts in src/scripts/main.ts, one init… call per feature. To turn a feature off, remove its call.

FeatureFile

Loader, page transition, adaptive header, back to topsite.ts

Counters and pixel statsnumber-flow.ts, pixel-stat.ts

When a visitor has reduced motion turned on, main.ts skips the loader, smooth scroll, page transitions, reveals and cursor, and every section stays visible and readable.

Contact form

The form checks the fields, then opens the visitor's mail app with the enquiry filled in, addressed to EMAIL. No server is involved. To post to a form service instead, replace the mailto: step in src/scripts/contact-form.ts.

Deploy

Set site in astro.config.mjs, then build. The output is a static folder.

bun run build     # writes dist/
HostBuild commandOutput folder
Cloudflare Pagesbun run builddist
Netlifybun run builddist
Vercelbun run builddist

Set the host's Node version to 22.12 or newer. The 404 page is dist/404.html.
